# `.github` — Community Health & Organization Governance

> Central governance repository for the **AIML Club – Oriental College of Technology, Bhopal**.

## Overview

This repository hosts organization-wide health files, community standards, contribution guidelines, issue and pull request templates, and profile configurations for the [AIMLCLUBOCT](https://github.com/AIMLCLUBOCT) organization.

GitHub uses this repository to provide default community health files to all other repositories in the organization when a repository does not have its own specific versions.

---

## Contents

- [**`profile/README.md`**](./profile/README.md): The official landing page rendered on the [AIMLCLUBOCT](https://github.com/AIMLCLUBOCT) organization overview.
- [**`CONTRIBUTING.md`**](./CONTRIBUTING.md): Global contribution workflow and code quality guidelines for all club repositories.
- [**`CODE_OF_CONDUCT.md`**](./CODE_OF_CONDUCT.md): Community behavior expectations and enforcement standards.
- [**`SECURITY.md`**](./SECURITY.md): Responsible disclosure policy, privacy rules, and security guidelines.
- [**`SUPPORT.md`**](./SUPPORT.md): Support avenues for students, club members, and open-source contributors.
- [**`pull_request_template.md`**](./pull_request_template.md): Default checklist for reviewing and submitting pull requests.
- [**`ISSUE_TEMPLATE/`**](./ISSUE_TEMPLATE): Standardized templates for reporting bugs, proposing projects, suggesting resources, and reporting documentation fixes.
- [**`templates/`**](./templates): Reusable starter templates for repositories, projects, workshops, and events.

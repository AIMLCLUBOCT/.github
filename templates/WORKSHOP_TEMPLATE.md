## 🚀 Running the Notebooks
You can run the workshop notebooks either locally or directly in your browser:

### Option A: Google Colab (Recommended for beginners)
Click the **Open In Colab** badge at the top of the notebook file.

### Option B: Local Setup
```bash
git clone https://github.com/AIMLCLUBOCT/Workshops.git
cd Workshops/[level]/[workshop-folder]
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
jupyter notebook
```
